# HD-1910-C001 / 7.4 V 配置

单舵机 P 阶跃响应对比见 [飞特测试台](../feetech1910_test_bench/README.md)：复用 XL330 的机械模型，使用 HD1910 动力学，无需训练策略。

这是一份独立的飞特配置和厂家动力学参考，不是本机已辨识模型。实机供电 7.4 V、位置 P=180；`profile.json` 保留尚未测量的项目保留来源状态。延迟先按用户指定沿用 XL330 的 3～6 个物理步，并标记为非实测假设。不覆盖 XL330 profile，不改变 61 维观测和 14 维策略动作，不控制第 15 个嘴部舵机。

## 这些文件分别是什么

- `profile.json`：官网规格、用户实机设置、待确认项。每个性能点保留测试电压。
- `config.py`：轻量配置读取、验证、CPU 参考模型加载和可选 mjlab 执行器工厂。
- `reference/m6.json`：飞特 HD1910 在 7.4 V 下的 BAM M6 拟合，原始字节不修改。
- `reference/actuator.py`：厂家控制律原文件，实际使用 `HD1910Actuator`；同文件的 STS3215 类不使用。
- `reference/provenance.json`、`LICENSE`：来源提交、文件 SHA-256、许可证。加载参考模型时先校验。

官方来源：

- 型号页：<https://www.feetechrc.com/510257>
- 厂家 BAM：<https://github.com/ftservo/ftservo-bam>（Gitee 镜像：<https://gitee.com/ftservo/ftservo-bam>）
- 固定提交：`bab3967811f0bec8b79898cb03e7f5812fe581f9`。

官网型号页与官方 Wiki 的摘要存在不同参数口径，本配置只采用型号页详细表，不能将不同电压、版本的值拼在一起。

## 可以从资料拿到的参数

型号详细表的性能测试点为 **4.8 V**，不是实机的 7.4 V：

| 参数 | 官方值 | 仿真中的用途 |
| --- | --- | --- |
| 堵转扭矩 | 9 kgf·cm，约 0.883 N·m @4.8 V | 短时边界参考，不能当持续输出上限 |
| 额定负载 | 2.2 kgf·cm，约 0.216 N·m @4.8 V | 负载/温升参考，不能替代整机热工况 |
| 空载速度 | 0.137 s/60° @4.8 V | 校核速度数量级；不线性外推到 7.4 V |
| 堵转/额定电流 | 1.2 A / 0.5 A @4.8 V | 电源及工作点参考，不等于已知固件限流参数 |
| 外形/重量 | 34×20×23 mm / 21±2 g | 替换舵机几何和质量的起点 |
| 减速比 | 320:1 | 结构/电机模型参考 |
| 齿轮虚位 | ≤0.5° | 厂家上界，不能当作每个实物的实测回差 |
| 编码器 | 4096 计数/圈 | 角度转换，不是整机安全活动范围 |

因此不要求用户先做危险的堵转试验，也不能把“厂家未写出的量”统一称为需要自己从零测量。

## 厂家已经辨识、可先作为先验的参数

7.4 V M6 文件已提供电机等效 `kt`、`R`、`armature`、库仑/粘滞/Stribeck/负载相关摩擦及 `command_delay`。控制律提供 `kp=32`、`error_gain=0.163`、`max_pwm=0.97`。这些是厂家台架辨识/实现值，不是官网规格换算出的值，也不是自己的整机实测。

无需为了第一版重复辨识所有摩擦项。先加载此参考，再用实际轨迹检查；偏差明显时才重新拟合。拟合 `kt` 与官网输出轴 KT 常数的口径不同，不能互相覆盖。`q_offset` 是厂家辨识台架的偏移，不可当作本鸭子每个舵机的零位。厂家 `command_delay` 也不等于串口、总线读写、软件周期全部加起来的端到端延迟。

## 第一轮需要测量/确认的内容

1. **P 增益响应**：按用户指定，实机 P 地址固定为 **21（0x15）**，P=180，与当前 microduck 驱动一致。厂家采集代码中的地址 50 只保留为来源记录，不应用于本机，也不再作为配置阻塞项。参考控制律默认 P=32，P=180 的小幅阶跃响应仍可用于校核模型，但不能因此宣称已经实测验证。
2. **端到端延迟**：初始按用户要求沿用 XL330 的 3–6 个物理步；它不是 HD1910 或香橙派的实测值。后续用实际香橙派、同一串口、15 颗舵机的命令→角度响应校核。不要把 50 Hz 策略步与 physics step 混用。
3. **电源与机械装配**：7.4 V 是用户给定标称值；记录整机动作时的实际电压/压降、整机与部件重量、实际关节限位。质心/惯量可先从更新后的 CAD 得到，再校核。舵盘、线材、支架、电池和主控也会影响质量分布。
4. **装机标定**：关节零位、正方向、身体 IMU 安装方向；这些由实物决定。

后续可选优化：每颗舵机摩擦/回差差异、不同负载的速度响应、温升与降额、再生电流和供电压降模型。厂家先验足够接近时，不必每项都重做台架辨识。

## 使用边界

`robot/servo_config.py` 的 `SERVO_DRIVER` 常量统一选择 `xl330` 或 `feetech1910`，当前默认为飞特。训练入口的普通/回差执行器和 `scripts/infer_policy.py` 的模型、P、电压默认值都读取所选 profile。CPU 回放电压随机化折叠为固定电压；回放脚本未复现训练的完整随机指令延迟。机械模型仍是原 Microduck，质量/惯量、回差几何仍需按实物校核；接通执行器选择不代表整机 Sim2Real 已验证。Backlash 模型也不能保留原版 ±1° 然后当作 HD1910 的实测值。

`load_reference_model()` 可在只有 BAM/numpy 的 CPU 环境中加载厂家模型，保持厂家的 P=32。`make_actuator_cfg()` 供后续任务显式使用：

```python
from mjlab_microduck.robot.feetech1910 import load_config, make_actuator_cfg

profile = load_config()
# P 地址为 21；延迟 [3, 6] 是用户指定沿用 XL330 的初始假设。
actuator_cfg = make_actuator_cfg(profile)
```

非法配置或显式缺失的延迟会明确报错，不自动切换另一种舵机。所有未实测假设保留标记；不会因此修改设备或启动训练。
