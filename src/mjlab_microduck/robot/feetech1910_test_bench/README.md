# 飞特 HD1910 单舵机测试台

不经过 RL，直接给位置阶跃，比较不同 P 的响应。仅在本机 CPU 上仿真，不连接串口、不修改实机，也不上传数据。无需 CUDA 或 W&B。

按用户确认，两个舵机机械模型相同，因此直接共享 `../xl330_test_bench/scene.xml` 和原有 STL，不复制网格。仅替换成 HD1910 BAM 控制器、M6 电机/摩擦参数、转动惯量与力矩上限。原 XL330 的脚本、模型和训练配置保持独立。这里没有注册新的 RL 训练任务。

## 运行

在 `microduck_rl` 目录执行：

```bash
uv run python scripts/feetech_testbench.py --p 16 32 64 180
```

默认 7.4 V；先保持 CAD 零位 0.5 秒，再增加 5°，运行到 3 秒。未指定 `--p`、`--voltage` 时读取 `feetech1910/profile.json` 的对应值。命令参数仅影响本次实验，不修改 profile 或训练配置。

改变负载和角度：

```bash
uv run python scripts/feetech_testbench.py --p 16 32 64 180 \
  --arm-mass 0.12 --initial-deg 0 --step-deg -5 --duration 5
```

`--arm-mass` 单位 kg，表示整个运动臂组件的总质量，默认 0.12 kg，与原 XL330 `testbench_constants.py` 相同。保留 CAD 的质心和外形，惯量按质量同比缩放；它不是在 120 g 之外再添加一个砝码。不代表鸭子关节的实际等效负载，实物变化还需更新重心/惯量。角度零点来自原 CAD，不是鸭子标定零位。

## 看结果和三维运动

终端打印每个 P 的最终误差、超调、稳定时间和电压饱和比例。结果保存在新的 `logs/feetech_testbench/<时间>/`：

- `response.png`：目标/实际角度、速度、电机力矩对比曲线。
- `p<P>.csv`：时间、请求目标、延迟后的目标、实际角度、速度、电机力矩、控制电压（rad、s、Nm、V）。记录的是每次物理步执行前的状态和本步施加的控制。
- `summary.json`：实验参数、仿真电机力矩上限和响应指标。默认输出目录唯一；`--out` 可指定新的或空目录。

Mac 上打开曲线：

```bash
open logs/feetech_testbench/<时间>/response.png
```

要看原测试台的三维运动，增加 `--view-p`，指定这次测试中某个 P；Mac 原生窗口需要用 `mjpython`：

```bash
uv run mjpython scripts/feetech_testbench.py --p 16 32 64 180 --view-p 32
```

Linux 可用 `uv run python` 执行同一命令（需要图形环境）。窗口循环回放本次计算出的轨迹，关闭即可退出。没有自动启动网页服务。

## 延迟、时间步和指标

- 默认 `--delay-steps 0`，用于分离舵机自身响应。加 `--delay-steps 3` 可模拟固定 3 个物理步延迟，`--dt 0.005` 时即 15 ms。这不是训练中随机 3～6 步的完整总线/软件时序；不额外叠加厂家 JSON 的 `command_delay`。
- 默认物理步 5 ms，与当前整机训练一致。可对照 `--dt 0.001` 检查响应是否受数值步长影响；改变时间步会改变相同 delay-steps 所代表的秒数。
- 最终误差保留正负号；另存最后 20% 采样的平均误差和峰峰摆幅。
- 超调沿阶跃方向计算；上升时间为首次到达阶跃幅度 10% 到 90% 的间隔。
- 稳定时间：从请求阶跃开始，进入目标 ±`--tolerance-deg`（默认 0.1°），且此后到记录结束都没有出界的时间；没有稳定则为 null。延迟计入稳定时间；记录窗口有限，不能据此保证长期稳定。
- 电压饱和比例是阶跃后的控制电压触及 PWM 限幅的采样占比，不是电流/温升测量。力矩是电机输出，不是减去摩擦后的净关节力矩。

不同 P 必须在相同负载、电压、角度和时序下比较，同时检查超调、响应速度、残余摆动与力矩。脚本不自动推荐“最佳 P”；仿真最优不等于实机最优。HD1910 仍采用厂家先验，尤其 P=180 的实机响应尚未验证。选定 P 后仍需核对实物，并使用相同动力学设置重新训练/微调 RL。
